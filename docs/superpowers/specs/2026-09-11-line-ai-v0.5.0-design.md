# Line AI v0.5.0 — Verified AI Workspace Tasarımı

## Amaç

Line AI'ı sohbet merkezli v0.4.1 uygulamasından, yaptığı gerçek işlemleri izlenebilir ve kanıtlanabilir hale getiren bir Windows çalışma alanına dönüştürmek. Ürün döngüsü `TRACE → CHECKPOINT → VERIFY → REPLAY`; ana mesajı “Yaptığını gösteren yapay zekâ.” ve “The AI you can audit.” olacaktır.

## Kaynak gerçeği

- Uygulama tabanı GitHub `v0.4.1` etiketinin işaret ettiği `09f837f` commit'idir.
- Bu commit GitHub `main` dalındaki `a4d289b` commit'inin doğrudan devamıdır.
- Kullanıcının verdiği ZIP, v0.4.1 kaynak paketidir; `.git` ve `PROJECT_LEDGER.md` paket politikasına göre ZIP dışında bırakılmıştır.
- v0.4.1 baseline: frontend 50/50 test, lint, TypeScript ve Vite build başarılı; Rust 22 test başarılı, gerçek Chrome/Gemini isteyen 2 test ignored.

## Mimari

### Görev oturumu çekirdeği

Her gerçek görev benzersiz bir `TraceSession` ile temsil edilir. Oturum; görev türü, durum, başlangıç/bitiş zamanı, plan adımları, Trace olayları, Evidence kayıtları, checkpoint referansları ve hesaplanmış sonuç sınıfını taşır. Şema sürümlüdür ve yerel depolamada v0.4.x sohbet verilerinden bağımsız bir anahtarda saklanır.

Trace olayları yalnız gerçek uygulama olaylarından üretilir. AI provider kanalındaki status/search/source/delta olayları, tarayıcı köprüsü sonuçları, terminal ve Git komutlarının native dönüşleri, checkpoint işlemleri ve artifact metadata'sı olay üretir. Gizli chain-of-thought saklanmaz; yalnız kısa karar özeti ve gerçek eylem metadata'sı saklanır.

### Kanıt ve sonuç hesabı

Evidence kayıtları kaynak türü, zaman, durum, ilişkilendirilen Trace olayı, güvenli özet ve gerektiğinde hash taşır. `VERIFIED`, `PARTIALLY_VERIFIED`, `UNVERIFIED`, `FAILED` ve `BLOCKED` sonuçları saf bir doğrulama fonksiyonuyla hesaplanır. Başarılı provider yanıtı tek başına `VERIFIED` üretmez; istenen kriterlerin gerçek başarılı kanıtları bulunmalıdır. Çalıştırılmayan alanlar `NOT RUN` olarak kalır.

### Native çalışma alanı motoru

Rust tarafında ayrı bir `workspace` modülü terminal, Git ve checkpoint işlemlerini yürütür. Terminal komutları PowerShell'i argüman listesiyle çağırır; cwd kanonikleştirilir, ortam değişkenleri allowlist ile sınırlandırılır, çıktı boyutu ve süre sınırlanır, stdout/stderr secret temizliğinden geçer ve gerçek exit code döner. Git okuma komutları shell interpolation kullanmadan `git -C <cwd> ...` olarak çalışır.

Checkpoint, repository'nin `.git`, `node_modules`, `target`, `dist` ve benzeri cache alanlarını kopyalamadan güvenli bir uygulama veri klasörüne dosya snapshot'ı oluşturur. Symlink/reparse noktaları izlenmez; dosya ve toplam boyut limitleri uygulanır. Restore öncesi etkilenecek yollar hesaplanıp kullanıcıya gösterilir; restore açık onayla yapılır ve sonucu ayrı Trace olayıdır.

### İzin modeli

Risk sınıfları `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`; kapsamlar `FILE_READ`, `FILE_WRITE`, `TERMINAL`, `NETWORK`, `BROWSER`, `GIT`, `EXTERNAL_APP` olarak tanımlanır. Kararlar “bu kez izin ver”, “bu görev boyunca izin ver” ve “reddet”tir. Mutating browser, terminal, restore ve tehlikeli Git işlemleri kullanıcı kararı olmadan çalışmaz. İzin kararı Trace'e yazılır.

### Provider ve yerel model

Mevcut OpenAI/Gemini davranışı korunur. Provider seçimi registry/capability katmanına alınır; OpenAI-compatible yerel endpoint yalnız açık kullanıcı ayarıyla ve varsayılan olarak loopback adresleriyle çalışır. Auto modu ücretli sağlayıcılar arasında mevcut kuralları korur; local başarısızlığında izinsiz cloud escalation yapmaz.

### Arayüz

Boş ana ekran BUILD, FIX, RESEARCH, AUDIT ve AUTOMATE kartlarını sunar. Aktif görevde geniş pencerede PLAN, LIVE WORK ve EVIDENCE görünür; dar pencerede aynı yüzeyler erişilebilir sekmelere dönüşür. Chat history, artifact KOD/ÖNİZLE/DIFF ve mevcut ayarlar korunur. Trace satırı kompakt başlar, ayrıntı kullanıcı açınca görünür. Sonuç kartı gerçek sayıları ve `NOT RUN` alanlarını gösterir.

Replay, Workflow, Project Memory ve Jury ağır yüzeyleri gerektiğinde lazy-load edilir. Jury yalnız gerçekten yapılandırılmış provider'ları çalıştırır ve kazananı ölçülen doğrulama/duration verileriyle belirler. Özellik hazır veya yapılandırılmış değilse çalışan bir hata/boş durum gösterilir; sahte sonuç üretilmez.

## Güvenlik ve veri

API anahtarları, Authorization/Cookie header'ları, yaygın token/password biçimleri Trace, terminal çıktısı, log ve proof bundle'a yazılmadan temizlenir. Workflow ve proof bundle import'ları sürüm ve boyut sınırıyla doğrulanır. URL, path, symlink, archive, HTML/SVG ve native IPC sınırları regresyon testleriyle korunur. Yeni telemetry eklenmez; trace/checkpoint verileri varsayılan olarak cihazda kalır.

## Yayın kanıtı

Kaynak değiştikçe eski kanıt `STALE_REVERIFY` kabul edilir. Release kapısı frontend verify, Rust fmt/test/release build, secret scan, fiziksel native açılış, açık/koyu/dar pencere kontrolleri, gerçek EXE sürüm/hash/launch, masaüstü shortcut smoke ve GitHub asset hash eşleşmesini ayrı ayrı kaydeder. Sertifika yoksa sonuç açıkça `UNSIGNED` olur.
