# Line AI v0.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Line AI v0.5.0'ı gerçek Trace, Checkpoint, Verification ve Replay kanıt zincirine sahip, Windows'ta fiziksel olarak doğrulanmış ve yayımlanmış bir Verified AI Workspace'e dönüştürmek.

**Architecture:** Sürümlü görev oturumu şeması React tarafındaki gerçek AI/browser/artifact olaylarını ve Rust tarafındaki terminal/Git/checkpoint sonuçlarını tek Trace/Evidence modelinde birleştirir. Saf doğrulama kuralları final durumu hesaplar; Mission Control bu kaynağı PLAN/LIVE WORK/EVIDENCE yüzeylerinde gösterir. Ağır Replay/Workflow/Memory/Jury yüzeyleri lazy-load edilir ve yerel veriler geriye uyumlu ayrı storage anahtarlarında saklanır.

**Tech Stack:** React 19, TypeScript 6, Vitest/Testing Library, Tauri 2, Rust 2021, reqwest/tokio, Tailwind CSS 4, Vite 8.

**Spec:** `docs/superpowers/specs/2026-09-11-line-ai-v0.5.0-design.md`

## Global Constraints

- Hedef sürüm bütün aktif metadata alanlarında `0.5.0` olmalıdır.
- Demo, fake progress, hardcoded PASS ve backend'e bağlı olmayan çalışan görünümlü özellik yasaktır.
- v0.4.x sohbet geçmişi, provider ayarları, tema, kısayollar, arşivler ve tercihler korunmalıdır.
- Secret hiçbir commit, ZIP, log, screenshot, Trace, proof bundle veya artifact'a girmemelidir.
- Yeni davranış test-first uygulanmalı; gerçek runtime kanıtı birim testinden ayrı tutulmalıdır.
- Light/dark/system, dar pencere, keyboard navigation ve `prefers-reduced-motion` korunmalıdır.
- GitHub Release'e yalnız `Line AI.exe` özel asset olarak yüklenmelidir; kaynak ZIP yalnız masaüstünde kalmalıdır.
- Vercel production deploy, `PROJECT_LEDGER.md` içindeki mevcut `PAUSED` kararı nedeniyle yapılmayacaktır; landing kaynağı güncellenecek ve durum finalde açıkça belirtilecektir.
