# Line CLI v0.1.0

Line CLI'nin ilk açık kaynak Windows sürümü yayımlandı.

## Öne çıkanlar

- 🧠 SmoothUI Chat Template çizgisinde açık ve koyu tema.
- 🔌 OpenAI ve Gemini sağlayıcıları arasında kontrollü otomatik geçiş.
- 🛡️ API anahtarlarını yalnızca masaüstü sürecinde kullanan güvenlik sınırı.
- 📁 Dosya sürükleyip bırakma, dosya seçme ve yerel çalışma bağlamı.
- 💬 Kalıcı sohbet geçmişi, sohbet arama ve sağ tık işlemleri.
- ⚡ Varsayılan olarak etkin `/truthmode` davranışı.
- 🧪 React, TypeScript ve Rust testleriyle doğrulanan yayın akışı.

## İndirilebilir dosyalar

- `Line CLI.exe`: Taşınabilir Windows uygulaması.
- `line-cli-src.zip`: Bu sürüm etiketine ait temiz kaynak arşivi.

## Güvenlik notu

Bu topluluk sürümü henüz ticari bir Authenticode sertifikasıyla imzalanmamıştır. Windows ilk çalıştırmada yayımlayıcı uyarısı gösterebilir. Dosyanın SHA-256 özeti GitHub sürüm varlıkları ve proje kayıtlarıyla karşılaştırılmalıdır.
