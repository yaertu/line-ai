# Line AI v0.4.1

- Sidebar'da **Tüm sohbetleri sil**: gerçek sohbet/mesaj sayılı, arşiv kapsamı açık onay; API anahtarları ve tercihler korunur.
- Bulut yanıtını bekleyen silme durumu, görünür hata ve yeniden deneme; bekleyen silme yeniden açılışta devam eder.
- Tek sohbet silinirken diğer arşivlerin silinmesine neden olan hata düzeltildi.
- Devam eden bulut kayıtlarının ve ilk yüklemenin silinen geçmişi geri getirmesi önlendi.

50 frontend testi ve 22 Rust testi geçti. İki dış ortama bağlı Rust testi atlandı. Native WebView2'de yerel, izole HTTP verileriyle light/dark, klavye, mobil, hata/tekrar ve yeniden açılış doğrulandı; kullanıcı bulut geçmişi silinmedi.

İndirilebilir dosya: `Line AI.exe`. Authenticode imzası yoktur; Windows yayımlayıcı uyarısı gösterebilir. Kaynak ZIP bu release'e yüklenmez.

Vercel deployment ve yeni provider/video doğrulaması bu sürümün kapsamına dahil değildir.
