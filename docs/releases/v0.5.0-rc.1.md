# Line AI v0.5.0-rc.1

Tarih: 11 Eylül 2026

v0.5.0-rc.1, denetlenebilir çalışma alanı çekirdeğini aday paket olarak ekler: sıralı Trace/Evidence kaydı, katı sonuç hesabı, yerel saklama ve kesinti recovery, SHA-256 proof bundle, workflow parser/hafıza çekirdeği ile native terminal, Git ve checkpoint komutları.

Native terminal gerçek stdout, stderr, exit code, süre aşımı ve iptal durumunu döndürür; çıktı redaksiyondan geçer. Git status mutasyon yapmaz. Checkpoint restore etkilenen yolları inceleme sonrasında yalnız açık onayla çalıştırır.

Bu release notu aday paketin kaynak kapsamını anlatır. Mission Control, replay, Jury ve local provider/model kullanıcı arayüzleri uygulanmadı. GitHub Release, EXE paketleme ve production dağıtım kanıtı yalnız bu aynı aday commit'i için üretilip doğrulandığında yayına eklenir.
