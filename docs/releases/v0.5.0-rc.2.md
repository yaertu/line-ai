# Line AI v0.5.0-rc.2

Tarih: 11 Eylül 2026

Bu aday sürüm, v0.5.0-rc.1 denetlenebilir çalışma alanı çekirdeğini korur ve varsayılan Line AI Cloud kökünü güncel production adresi `https://lineai-eta.vercel.app/api/v1` ile eşitler.

Mission Control, replay, Jury ve local provider/model kullanıcı arayüzleri uygulanmadı. Bu aday sürüm, tamamlanmış ürün yüzeyi olarak sunulmaz.

GitHub Release, EXE paketleme ve production dağıtım kanıtı yalnız bu aynı aday commit'i için üretilip doğrulandığında yayına eklenir.
