# Line AI v0.7.0 — Ultra Premium çalışma alanı

Line AI v0.7.0, sohbet ekranını yüzen grafit paneller, odaklı mint vurgular, canlı Engine sağlık rozeti ve daha güçlü bir mesaj yazma yüzeyiyle yeniler. Kod, DIFF ve önizleme çalışma alanı açıldığında sohbetin yanında bağlamsal olarak çalışmayı sürdürür.

Engine capabilities API’si anahtarı açıklamadan etkinlik durumu, kapsamlar, sona erme zamanı, günlük ve aylık sıfırlanma zamanları, kalan birim/maliyet bütçesi ve aylık istek sayısını döndürür. Ayarlar → Yapay zekâ ekranı bu bilgileri kolay okunur kartlarda gösterir.

## Doğrulama hedefleri

- Frontend lint, TypeScript, Vitest ve production build
- Cloud API TypeScript ve Vitest
- Rust/Tauri testleri ve Windows release derlemesi
- Canlı Line AI Engine anahtar, kota ve üretim smoke testi
- GitHub ve masaüstü EXE/ZIP SHA-256 eşleşmesi
