# Local models

v0.5.0 yerel provider veya local model bağlantısı sunmaz. Yerel endpoint yapılandırması, model listesi, health kontrolü, otomatik yönlendirme veya cloud'a otomatik geçiş uygulanmadı.

Mevcut Trace/Verification/Workspace çekirdeği, bir local model entegrasyonunun kanıtlarını ileride kaydedebilmek için altyapı sağlar; entegrasyonun kendisi değildir.
