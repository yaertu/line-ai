# Üçüncü Taraf Bildirimleri

## SmoothUI

Line AI arayüzünün bazı temel sohbet bileşenleri SmoothUI kaynaklarından uyarlanmıştır.

- Proje: https://github.com/educlopez/smoothui
- Belge: https://smoothui.dev/docs/templates/chat
- Telif: Copyright (c) 2024 Eduardo Calvo
- Lisans: MIT

SmoothUI telif ve izin bildirimi, bu dağıtımdaki `LICENSE` dosyasında korunmuştur.

## Arayüz araştırma kaynakları

Line AI'ın erişilebilir Sidebar, komut araması, durum geri bildirimi, dosya bırakma, ayar, düşünme, araç ve kod farkı akışları tasarlanırken aşağıdaki açık arayüz kataloglarının belgeleri karşılaştırmalı tasarım referansı olarak incelenmiştir. Bu projede kataloglardan bağımsız ve Line AI'ın gerçek uygulama durumuna bağlı bileşenler uygulanmıştır; bir bileşenin kaynak kodu doğrudan alındığında kendi lisans bildirimi ayrıca korunur.

- Animate UI — https://animate-ui.com/
- Magic UI — https://magicui.design/
- Spectrum UI — https://ui.spectrumhq.in/
- ReUI — https://reui.io/components
- Cult UI — https://www.cult-ui.com/
- Agent Elements — https://agent-elements.21st.dev/
- Tool UI — https://www.tool-ui.com/
- Kokonut UI — https://kokonutui.com/

JavaScript ve Rust bağımlılıkları kendi lisanslarına tabidir. Kesin sürümler `pnpm-lock.yaml` ve `src-tauri/Cargo.lock` dosyalarında sabitlenmiştir.
